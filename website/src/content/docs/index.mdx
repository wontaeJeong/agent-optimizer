**내 Agent를 어떤 조건에서 개선했는지 확인하는 실험 도구.** Agent Optimizer는 Python CLI·대화형 TUI에서 Agent 소스, 실행 방법, 데이터셋, 평가기와 Optimizer를 조합해 비교합니다. 웹 서버를 설치할 필요는 없습니다.

## 어디서 시작할까요?

지금 할 일에 맞는 경로 하나를 고르세요. 첫 실행에 구조 문서를 미리 읽을 필요는 없습니다.

**첫 실행**은 모델·Docker 없이 연결을 확인하는 합성 fixture입니다. **내 Agent 실험**은 선택한 데이터셋과 분리된 평가기가 있어야 하며, **팀 개발**은 공통 계약과 중앙 등록을 추가합니다.

## 실험은 이렇게 진행됩니다

[전체 구조와 실행 흐름 그림](/agent-optimizer/concepts/overview/)에서 구성 요소가 어떻게 이어지는지 확인할 수 있습니다. 원본에서 분리한 Agent 후보를 Harness가 공개 과제에 실행하고 Evaluator가 결과를 채점합니다. 데이터셋은 사용자가 선택하며, Optimizer는 허용된 파일만 바꿉니다. 최종 선택 후 보고서를 읽습니다.

:::note[합성 데모와 실제 평가]
첫 실행은 모델·Docker 없이 배선을 확인하는 **합성 fixture**입니다. 데모의 점수 변화는 실제 Agent의 개선이나 모델 성능을 입증하지 않습니다. 실제 실행에는 대상 Agent의 명령, 수정 허용 범위, 데이터셋과 신뢰할 평가기가 필요합니다.
:::
